Geokode

A self-hosted geocoder written in Rust. It indexes named OpenStreetMap objects and optional address files into a directory it serves from memory maps.

Rust Self-Hosted FST + kd-tree REST API Docker Ready AGPL-3.0-or-later

Features

Named OSM objects

Settlements, admin boundaries, named streets and POIs from any PBF up to the planet. Each result carries osm_type, osm_id, osm_key and osm_value, so a caller fetches the outline from Overpass.

Admin containment

Boundary relations become polygons. Every record gets its country and country_code from level 2, its state from level 4 and its city from the most local of 8, 7 and 6, or the nearest town when no boundary names one.

Ranking

An exact name beats a prefix. A city beats a same-named street or POI, larger settlements come first, and a wikidata tag breaks ties. With lat/lon, the nearer of two same-named objects comes first.

Area filter

Springfield, Illinois keeps only records inside a boundary named Illinois. Springfield Illinois without the comma works too when nothing is named that.

Streets

The ways of one street merge into a single record per name and municipality, placed on its longest way, with the bbox of all of them.

Addresses

House numbers come from address inputs to the build: an OSM PBF, OpenAddresses CSV or GeoJSON. A query that starts with a number puts them first.

Reverse

Inside an address input's coverage, the nearest addresses. Elsewhere, the nearest settlements within 25 km.

Build once, serve from disk

geokode build streams the PBF in passes with node coordinates in a sorted file, so its memory does not grow with the node count. geokode serve maps the index, so a Swiss index starts in 7 MB of RSS.

Request caps

Queries of 1 to 256 characters, limit up to 50, batches of up to 100 queries in 64 KiB. Anything else answers 400 with a JSON error.

Optional JWT Auth

Set GEOKODE_JWT_SECRET and the geocoding endpoints require an HS256 bearer JWT with sub, exp and role claims. Leave it unset and every request is allowed. Health, readiness and metrics stay public. The compose file sets the secret to change-me-in-production.

API Endpoints

GET /forward?q=Paris,+France&limit=5&lat=48.8&lon=2.3
Text to places, best first. limit, lat and lon optional
GET /autocomplete?q=zur&limit=10
The same search without the typo fallback
GET /reverse?lat=47.37&lon=8.54&limit=5
Nearest addresses, or nearest settlements outside address coverage
POST /batch
{"queries": [...], "limit": 1}, one result list per query
GET /health
Service status and record count
GET /healthz
Liveness probe, 200 while the process runs
GET /readyz
Readiness probe, 503 while the index is empty
GET /metrics
Prometheus request counters

Quick Start

cargo install --path crates/geokode-cli
geokode build --pbf switzerland-latest.osm.pbf --out ch-index
geokode serve --index ch-index --bind 0.0.0.0:3000

curl "http://localhost:3000/forward?q=Zurich"
curl "http://localhost:3000/reverse?lat=47.37&lon=8.54"
